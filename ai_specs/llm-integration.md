# LLM Integration — NOT APPLICABLE

> **OpenOwls SDD** — Status for this project: **Not applicable.**

OpenOwls Hub has **no LLM layer**. It is a static showcase/directory site; it makes no
model calls at build time or run time and holds no API keys. (The *apps* that the Hub
links to may use LLMs, but each of those lives in its own repository and documents its
own LLM integration there.)

If this site ever needs an LLM feature, restore this file from the SDD template and
document the model, prompts, and guardrails here.
